# cloud-mall Agent Instructions

多模块电商项目，Spring Boot 3 + MyBatis-Plus + MySQL + Redis + ES + RocketMQ + MinIO。

规则文件按主题拆分，通过 `opencode.json` 自动加载：

| 文件 | 内容 |
|------|------|
| `.agents/build.md` | 构建命令、测试、本地开发、模块结构 |
| `.agents/code-style.md` | 命名、import、格式、集合、MP 查询 |
| `.agents/domain-convention.md` | 包结构、分层、异常、枚举、分页、审核、全局返回 |
| `.agents/checklist.md` | 提交前检查清单 |
